HTML-first examples

Each page below is a server-rendered test page used to check that the reference implementation, PR #24 (final version b248e1e4ae), neither breaks hydration nor changes what the user sees. Every name opens a live demo (the flag on, full size), and the source link next to it shows the page's code. The /off/ version of each demo is the same page with the flag off, if you want to compare.

The gzip column is the size of the whole document with the flag on, followed by the change against the flag-off size. Most pages shrink; a few get slightly larger, either because there is little static markup to remove or because the registry row costs more than it saves. Overall the 41 pages go from 1,023,906 to 586,852 gzipped bytes (−42.7%) and from 9,280,754 to 1,977,902 bytes of inlined Flight (−78.7%). The median page saves 7.8%.
