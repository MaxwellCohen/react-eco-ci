HTML-first examples

These are the 45 server-rendered test pages used to check that HTML-first Flight (PR #28, source 6f7f804093, React build d5dd0f51, measured November 23, 2026) neither breaks hydration nor changes what the user sees. Each name opens the live page with the feature on. off shows the same page with it off. registry shows the earlier alternative (PR #24, built November 19), available for the 41 original pages.

The gzip column is the size of the whole document with the feature on, then the change from the off size. Most pages shrink. A few grow slightly because they have little static markup to remove. Across the 41 original pages gzipped bytes fall from 1,023,745 to 594,628 (−41.9%) and inlined Flight from 9,282,481 to 2,397,212 bytes (−74.2%); the median page saves 6.2%. Across all 45 pages gzipped bytes fall from 1,089,665 to 651,644 (−40.2%). Pages that grow: repeated-long-strings (+1,461 B) and four others by 2–17 B. All 45 pass the browser checks in Chromium 139 and Firefox 159.
